## 7. 真实外部检查

- DeepSeek：脱敏面试 Fixture 返回 `INTERVIEW`、`HIGH`、需要回复，正确提取公司、
  岗位、面试时间、回复截止时间和会议链接。
- 163：专用测试账户 IMAP 与 SMTP 连接均成功。
- 163 能力探测：支持 `UIDPLUS`，不支持 `MOVE`。Executor 因而采用“COPY →
  持久化 COPYUID 检查点 → UID STORE Deleted → UID EXPUNGE”；复制或删除结果不明确
  时进入 `UNKNOWN` 且不自动重试。
- 163 真实归档/恢复：用户指定邮件 ID 24 后，归档审核和恢复审核均为
  `SUCCEEDED`。归档后服务器确认 `JobMailArchive` 目标 UID 存在且 INBOX 原 UID
  不存在；恢复后确认新 INBOX UID 存在且旧归档 UID 不存在。
- 原始身份 `UIDVALIDITY:UID=1:1784121555` 全程未修改；归档当前指针更新为
  `257:1785405524`，恢复后更新为 `1:1784121559`。复用两个原审核任务执行时，
  各自仍只有一条 `SUCCEEDED` 执行记录，未再次访问 IMAP。
- 163 增量同步：连续两次均为 `examined=0, created=0, skipped=0, failed=0`，说明本轮
  没有新邮件可用于验证“新增一次、自动启动工作流”。
- 本轮没有执行 SMTP 真实发送。发送会产生外部影响，必须先生成新的 `SEND_REPLY`
  审核任务并由用户确认，不复用历史批准记录代替本轮确认。
- 当前 `.env` 中 checkpoint 密钥仍为占位值。真实工作流启动前必须换成有效的
  16/24/32 字节 AES 密钥；不得把临时明文或占位值用于验收。
